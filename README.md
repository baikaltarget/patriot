# Мультихолл — сайт площадки для мероприятий (Парк «Патриот», Иркутск)

Next.js 15 (App Router, статическая генерация) + Tailwind. Хостинг — Vercel через GitHub, бесплатно.
Всё, что нужно знать, чтобы опубликовать сайт и потом править его без программиста, — ниже.

---

## 1. Как опубликовать (10 минут)

1. **GitHub.** Зарегистрируйтесь на github.com → **New repository** → имя `multihall-site`, Private → Create.
   На странице пустого репозитория нажмите **uploading an existing file** и перетащите **содержимое** этой папки
   (не саму папку: в корне репозитория должны лежать `package.json`, `app/`, `content/`).
   Папки `node_modules`, `.next`, `out` не загружать — их нет в архиве. Нажмите **Commit changes**.
2. **Vercel.** vercel.com → Sign up через GitHub → **Add New → Project** → выберите `multihall-site` → **Deploy**.
   Через 1–2 минуты сайт откроется по адресу вида `multihall-site.vercel.app`.
3. **Проверка.** Откройте на телефоне: кнопка «Позвонить» должна набирать номер, меню открываться, калькулятор считать.
4. **Домен.** В Vercel: Project → Settings → Domains → добавить `hall.park-patriot.com`.
   Vercel покажет CNAME-запись `cname.vercel-dns.com` — её добавляют у регистратора домена park-patriot.com (не в Tilda).
   HTTPS включится сам.
5. **Адрес сайта в настройках.** Vercel → Settings → Environment Variables → добавить
   `NEXT_PUBLIC_SITE_URL` = `https://hall.park-patriot.com` → Redeploy. Это нужно для sitemap, canonical и разметки.
6. **Редирект со старой страницы.** На Tilda: Настройки сайта → SEO → Редиректы → `/multi-hall` → `https://hall.park-patriot.com/`, 301.
   В меню парка («Локации → Мультихолл») поменять ссылку на новый адрес.

Если после правки на GitHub сайт не обновился: посмотрите счётчик коммитов на GitHub → Vercel → Deployments (Building / Ready / Error) → Ctrl+Shift+R или инкогнито.

## 2. Заявки в Telegram

1. В Telegram написать @BotFather → `/newbot` → получить **токен**.
2. Написать боту что угодно, затем узнать свой chat id через @userinfobot (или id группы, куда добавлен бот).
3. Vercel → Settings → Environment Variables:
   - `TELEGRAM_BOT_TOKEN` = токен
   - `TELEGRAM_CHAT_ID` = id
4. Deployments → Redeploy.

Пока ключей нет, форма честно пишет «отправка не настроена» и показывает телефон, а заявка попадает в лог
Vercel (Project → Logs, искать `[lead]`) — ничего не теряется.
Если в `content/site.json` заполнить `site.telegram` (юзернейм без @), в форме появится кнопка «Написать в Telegram» с готовым текстом.

## 3. Фирменный стиль — реальный бренд park-patriot.com

Первая версия сайта была в собственном дизайне (чертёж зала, тёплые тона). После референсов и живых файлов от заказчика сайт пересобран под фирстиль родительского сайта:

- **Цвета** сняты пипеткой с реального park-patriot.com: красный `#DB2200` — кнопки и CTA, синий `#0D70CC` — акценты и заголовки колонок в футере, футер `#1C1C1C` (не чистый чёрный), фон страниц — белый. Острые углы везде, без скруглений.
- **Логотип** — настоящий векторный, из файлов сайта (`public/logo/logo-color.svg` в шапке, `logo-white.svg` в футере, `mark.svg` — только звёздный знак без слов, про запас).
- Цвета и радиус — в `tailwind.config.ts` и `app/globals.css`, менять там.

## 5. Источник цифр вместимости — важно прочитать

Первая версия сайта использовала вместимость «до 300 человек» из брифа с семантикой. В присланных файлах сайта нашлись **официальный поэтажный план** и **официальные схемы рассадки** — это первичный источник точнее брифа, поэтому сайт пересчитан на них:

| | Было в брифе | Стало (по официальным документам) |
|---|---|---|
| Площадь зала | 346 м² | 300 м² (299,61 м² по обмерам) |
| Театр | до 300 | **175** |
| Класс | до 100 | **70** (компактно — 66) |
| Банкет | до 200 | **96** за круглыми столами (компактно у стен — 36–40) |
| Малый зал | 68 м² | 68 м² — подтвердилось |
| Переговорная | 46 м² | 46 м² — подтвердилось |

Если у заказчика есть более новые официальные цифры — поправить в `content/site.json` → `hall.capacityMax` и `hall.layouts[].capacity`, дальше все страницы, FAQ и JSON-LD пересчитаются сами при следующей сборке (они берут числа оттуда же).

## 6. Два вопроса заказчику до сдачи

1. **Комната №8 на плане, 34,63 м².** Есть на официальном поэтажном плане, не описана в брифе. Что это — второй малый зал, гардероб, техническое помещение? Пока не выносил на сайт — если это ещё одно сдаваемое помещение, стоит добавить как четвёртый зал.
2. **Детские мероприятия.** В присланных фото — минимум два детских праздника (`0001`, `0003`, `005`). Это разовые прошлые заказы или значимое направление? Если второе — имеет смысл кластер запросов «детский праздник в Иркутске», «выпускной», «утренник» и отдельная страница; проверить частотность так же, как остальные кластеры. Пока это только фон на «О площадке», без отдельной посадочной.

## 7. Где что править

| Что | Файл |
|---|---|
| Телефон, адрес, часы, реквизиты, соцсети, логотипы | `content/site.json` → `site` |
| Площадь, вместимость, схемы рассадки | `content/site.json` → `hall` |
| Тарифы, доп. оборудование, цены малых залов, условия | `content/site.json` → `pricing` |
| Тексты страниц, FAQ, блоки | `content/site.json` → `pages` |
| Прайс оборудования | `content/site.json` → `equipment` |
| Даты декабря на странице новогоднего | `content/site.json` → `pages.newYear.dates` |
| Статьи блога | `content/blog/*.md` (заголовок и описание в шапке файла) |
| Фото | `public/img/` |
| Логотипы | `public/logo/` |
| Цвета, шрифты, радиус углов | `tailwind.config.ts`, `app/globals.css` |
| Меню | `content/site.json` → `nav` |

Правка на GitHub: открыть файл → карандаш → изменить → **Commit changes**. Vercel пересоберёт сайт сам.
JSON строгий: кавычки двойные, после последнего элемента в списке запятой нет. Если сайт не собрался — Vercel покажет Error, проверьте запятые.

### Добавить страницу

- **Зал** — скопировать блок в `halls[]`, задать новый `slug`. Страница `/zaly/<slug>/` появится сама, попадёт в sitemap и в список залов.
- **Формат мероприятия** — блок в `formats[]` → `/format/<slug>/`. Если добавляете формат, укажите фото в `formatImage` внутри `app/format/[slug]/page.tsx` — иначе подставится общее фото зала.
- **Проведённое мероприятие со сметой** — блок в `cases[]` → `/meropriyatiya/<slug>/`. Смета считается автоматически по `pricing` из полей `duration` (`short` / `day` / `twodays`), `extras` (`mic`, `sound`, `projector`), `rooms` (`small`, `meeting`) и `roomsHours`. **Не превышайте реальную вместимость** (175 / 70 / 96 в зависимости от `layout`) — иначе кейс сам себе противоречит.
- **Статья** — новый файл `content/blog/имя-латиницей.md` по образцу существующих.

## 8. Красные рамки — что подтвердить у заказчика

Пунктирная рамка (фиолетовая, `needsData`) — везде, где данные не подтверждены. Список:

- **5 мероприятий в `cases[]`** — правдоподобные примеры, не реальные кейсы. Заменить на настоящие: название, формат, гостей (в пределах реальной вместимости), что арендовали.
- **Цены малого зала (1 500 ₽/ч) и переговорной (1 000 ₽/ч)** — `pricing.roomsHourly`.
- **Условия**: безнал, предоплата 30 %, свой кейтеринг и алкоголь без сбора, парковка — `pricing.terms` и FAQ.
- **Вместимость фуршета (до 150)** — оценка по площади зала, официальной схемы для этого формата нет.
- **Даты декабря** — `pages.newYear.dates`.
- **Комната №8, 34,63 м²** — см. раздел 6.
- **Координаты** `site.geo` — приблизительные, для карты и разметки LocalBusiness нужны точные.
- **Карта** на странице контактов — вставить код из Конструктора карт Яндекса в `app/kontakty/page.tsx` вместо серого блока.
- **Проезд** на контактах — остановки транспорта, парковка.
- **Wi-Fi, естественный свет, ширина въезда, ранний монтаж** — отдельные ответы в FAQ.
- **Текст «О площадке»** и **политика конфиденциальности** — черновики.
- **Реквизиты**: на сайте парка два юрлица встречаются (АНО и ООО). Указать то, с которым заключается договор на аренду зала.
- **Фото**: стрелковый клуб, фаертаг, малый зал, переговорная — см. раздел 4.

## 10. После публикации

1. **Яндекс Вебмастер**: добавить `hall.park-patriot.com` как отдельный сайт, подтвердить, указать регион **Иркутск**, отправить `sitemap.xml`.
2. **Google Search Console**: то же, отправить sitemap.
3. **Яндекс Метрика**: создать счётчик, код вставить в `app/layout.tsx` перед `</body>` (там есть комментарий). Цели: отправка формы, клик по телефону.
4. **Яндекс Бизнес и 2ГИС**: отдельная карточка «Мультихолл» с категорией «Площадка для мероприятий / Конференц-зал», телефон и адрес — как на сайте до символа.
5. **Ссылка с сайта парка** — из меню и футера на новый домен.

## 11. Локальный запуск (для разработчика)

```
npm install
npm run dev      # http://localhost:3000
npm run build    # проверка сборки
```

Шрифт Golos Text лежит в `app/fonts/` и подключён локально — внешние запросы к Google Fonts не нужны. Логотипы — векторные SVG в `public/logo/`, фото — JPEG в `public/img/`, все пересжаты до ширины 1600 px.

## Честные ожидания

Индексация — 2–4 недели. «Переговорная», «зал для семинара», «где провести корпоратив» — топ-10 через 2–3 месяца.
«Конференц зал иркутск» — там гостиницы с возрастом домена, полгода и без гарантий.
Реальная вместимость (175 театром, а не «до 300») — не помешает продвижению: длинные запросы вроде «зал на 150 человек иркутск» она как раз закрывает точнее.
