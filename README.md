# Мультихолл — сайт площадки для мероприятий (Парк «Патриот», Иркутск)

Next.js 15 (App Router, статическая генерация) + Tailwind. Хостинг — Vercel через GitHub, бесплатно.
Всё, что нужно знать, чтобы опубликовать сайт и потом править его без программиста, — ниже.

---

## 1. Как опубликовать (10 минут)

1. **GitHub.** Зарегистрируйтесь на github.com → **New repository** → имя `multihall-site`, Private → Create.
   На странице пустого репозитория нажмите **uploading an existing file** и перетащите **содержимое** этой папки
   (не саму папку: в корне репозитория должны лежать `package.json`, `app/`, `content/`).
   Папки `node_modules`, `.next`, `out` не загружать — их нет в архиве. Нажмите **Commit changes**.
2. **Vercel.** vercel.com → Sign up через GitHub → **Add New → Project** → выберите `multihall-site` → **Deploy**.
   Через 1–2 минуты сайт откроется по адресу вида `multihall-site.vercel.app`.
3. **Проверка.** Откройте на телефоне: кнопка «Позвонить» должна набирать номер, меню открываться, калькулятор считать.
4. **Домен.** В Vercel: Project → Settings → Domains → добавить `hall.park-patriot.com`.
   Vercel покажет CNAME-запись `cname.vercel-dns.com` — её добавляют у регистратора домена park-patriot.com (не в Tilda).
   HTTPS включится сам.
5. **Адрес сайта в настройках.** Vercel → Settings → Environment Variables → добавить
   `NEXT_PUBLIC_SITE_URL` = `https://hall.park-patriot.com` → Redeploy. Это нужно для sitemap, canonical и разметки.
6. **Редирект со старой страницы.** На Tilda: Настройки сайта → SEO → Редиректы → `/multi-hall` → `https://hall.park-patriot.com/`, 301.
   В меню парка («Локации → Мультихолл») поменять ссылку на новый адрес.

Если после правки на GitHub сайт не обновился: посмотрите счётчик коммитов на GitHub → Vercel → Deployments (Building / Ready / Error) → Ctrl+Shift+R или инкогнито.

## 2. Заявки в Telegram

1. В Telegram написать @BotFather → `/newbot` → получить **токен**.
2. Написать боту что угодно, затем узнать свой chat id через @userinfobot (или id группы, куда добавлен бот).
3. Vercel → Settings → Environment Variables:
   - `TELEGRAM_BOT_TOKEN` = токен
   - `TELEGRAM_CHAT_ID` = id
4. Deployments → Redeploy.

Пока ключей нет, форма честно пишет «отправка не настроена» и показывает телефон, а заявка попадает в лог
Vercel (Project → Logs, искать `[lead]`) — ничего не теряется.
Если в `content/site.json` заполнить `site.telegram` (юзернейм без @), в форме появится кнопка «Написать в Telegram» с готовым текстом.

## 3. Где что править

| Что | Файл |
|---|---|
| Телефон, адрес, часы, реквизиты, соцсети | `content/site.json` → `site` |
| Тарифы, доп. оборудование, цены малых залов, условия | `content/site.json` → `pricing` |
| Тексты страниц, FAQ, блоки | `content/site.json` → `pages` |
| Прайс оборудования | `content/site.json` → `equipment` |
| Даты декабря на странице новогоднего | `content/site.json` → `pages.newYear.dates` |
| Статьи блога | `content/blog/*.md` (заголовок и описание в шапке файла) |
| Фото | `public/img/` |
| Меню | `content/site.json` → `nav` |
| Цвета и шрифты | `tailwind.config.ts`, `app/globals.css` |

Правка на GitHub: открыть файл → карандаш → изменить → **Commit changes**. Vercel пересоберёт сайт сам.
JSON строгий: кавычки двойные, после последнего элемента в списке запятой нет. Если сайт не собрался — Vercel покажет Error, проверьте запятые.

### Добавить страницу

- **Зал** — скопировать блок в `halls[]`, задать новый `slug`. Страница `/zaly/<slug>/` появится сама, попадёт в sitemap и в список залов.
- **Формат мероприятия** — блок в `formats[]` → `/format/<slug>/`.
- **Проведённое мероприятие со сметой** — блок в `cases[]` → `/meropriyatiya/<slug>/`. Смета считается автоматически по `pricing`
  из полей `duration` (`short` / `day` / `twodays`), `extras` (`mic`, `sound`, `projector`), `rooms` (`small`, `meeting`) и `roomsHours`.
- **Статья** — новый файл `content/blog/имя-латиницей.md` по образцу существующих.

## 4. Красные рамки — что подтвердить у заказчика

На сайте пунктирной красной рамкой обведено всё, что придумано или не подтверждено. Каждое место
помечено в `content/site.json` полем `"needsData": true`. Когда данные подтверждены — поменять на `false`
или удалить поле. Выключить все рамки разом: `flags.showNeedsDataFrames: false`.

Список:
- **5 мероприятий в `cases[]`** — придуманы как образец. Заменить на реальные: название, формат, гостей, что арендовали.
- **Цены малого зала (1 500 ₽/ч) и переговорной (1 000 ₽/ч)** — `pricing.roomsHourly`.
- **Условия**: безнал, предоплата 30 %, свой кейтеринг и алкоголь без сбора, парковка — `pricing.terms` и FAQ.
- **Вместимость по рассадкам** (300 / 100 / 200 / 300) — `hall.layouts`.
- **Даты декабря** — `pages.newYear.dates`.
- **Адрес**: на сайте парка «ул. Ширямова, 38», в запросах «38/3». Уточнить и поправить `site.address`, `site.addressStreet`.
- **Координаты** `site.geo` — сейчас приблизительные, для карты и разметки LocalBusiness нужны точные.
- **Карта** на странице контактов — вставить код из Конструктора карт Яндекса в `app/kontakty/page.tsx` вместо серого блока.
- **Проезд** на контактах — остановки транспорта.
- **Wi-Fi, естественный свет, ширина въезда, ранний монтаж** — отдельные ответы в FAQ.
- **Текст «О площадке»** и **политика конфиденциальности** — черновики.
- **Реквизиты**: на сайте парка два юрлица (АНО и ООО УЦДПО «СК ПАТРИОТ»). Указать то, с которым заключается договор.

## 5. Фото

Сейчас вместо фото серые плашки с именами файлов. Нужно положить в `public/img/`:

- `hall-01.jpg … hall-05.jpg` — большой зал (первое — главное, горизонтальное)
- `conf-01 … conf-05` — конференции; `corp-01 … corp-05` — корпоративы; `venue-01 … venue-05` — концерты/выставки
- `malyy-zal-01.jpg`, `peregovornaya-01.jpg`
- `park-shooting.jpg`, `park-firetag.jpg` — тир и фаертаг
- `case-<slug>-01.jpg … 03` — для каждого мероприятия из `cases[]`

Перед загрузкой: squoosh.app → WebP → ширина 1600 px (тогда расширение `.webp`, и его надо поменять в коде плашек — или оставить `.jpg`).
Загрузка сразу в папку: `github.com/<user>/multihall-site/upload/main/public/img`.
После загрузки в `components/PhotoSlot.tsx` поменять `placeholder = true` на `false` — плашки станут фотографиями.

Фото на текущей странице `park-patriot.com/multi-hall` лежат на CDN Tilda. **Не отключать Tilda, пока фото не скачаны.**

## 7. После публикации

1. **Яндекс Вебмастер**: добавить `hall.park-patriot.com` как отдельный сайт, подтвердить, указать регион **Иркутск**, отправить `sitemap.xml`.
2. **Google Search Console**: то же, отправить sitemap.
3. **Яндекс Метрика**: создать счётчик, код вставить в `app/layout.tsx` перед `</body>` (там есть комментарий). Цели: отправка формы, клик по телефону.
4. **Яндекс Бизнес и 2ГИС**: отдельная карточка «Мультихолл» с категорией «Площадка для мероприятий / Конференц-зал», телефон и адрес — как на сайте до символа. Просить клиентов оставить отзыв.
5. **Ссылка с сайта парка** — из меню и футера на новый домен.

## 8. Локальный запуск (для разработчика)

```
npm install
npm run dev      # http://localhost:3000
npm run build    # проверка сборки
```

Шрифты (Golos Text, JetBrains Mono) лежат в `app/fonts/` и подключены локально — внешние запросы к Google Fonts не нужны.
